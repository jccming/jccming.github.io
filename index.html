让优化目标，理解图像结构。

真实图像的不同位置不需要相同的约束：边缘与纹理需要保留结构，平坦区域需要更充分地抑制噪声。核心是在重建误差之外引入空间结构信息，让优化由“全图同等对待”转为“按位置分配约束”。

01 / WARM-UP初始去噪先得到较稳定的结构参考，减少直接从噪声估计边缘的干扰。
02 / STRUCTURE结构感知通过 Sobel 梯度与分位数分区，估计局部结构复杂度。
03 / SPATIAL MAP空间权重图对区域赋权并进行局部平滑，在第二阶段固定该权重图。
04 / OPTIMIZATION差异化优化边缘强化结构约束，平坦区域给予去噪更大自由度。
Lspatial = meanp [ w(p) · | fθ(y)p − tp | ]

示意表达：w(p) 表示固定的空间权重；t 为自监督训练构造的目标。实际训练还结合有效像素掩码及辅助项。

结构分支回答“需要看多大的范围”，空间损失回答“不同位置应怎样优化”。二者分别处理尺度与空间上的非均匀性；区域划分和具体权重是实现选择。

# 当前查询块与低分辨率参考块的结构距离
D = torch.cdist(query_ref_chunk, key_ref)
ds, ids = D.topk(k, largest=False, dim=1)

# 只比较 Top-K 候选的梯度差异
dg = (query_grad_chunk[:, None] - key_grad[ids])
dg = dg.abs().mean(-1)
ds = ds / ds.mean(1, keepdim=True).clamp_min(1e-8)
dg = dg / dg.mean(1, keepdim=True).clamp_min(1e-8)

# alpha 由局部边缘强度决定；平坦块 alpha = 0
score = (1 - alpha) * ds + alpha * dg
selected = ids.gather(1, score.argmin(1, keepdim=True))
refilled = noisy_patches[selected.squeeze(1)]

最终取值来自平均池化后的含噪图像块。Top-K 用于筛选，实际选择一个候选，不对候选直接求平均。

独立尺度分支：建模、对齐与融合PYTORCH / 核心逻辑
model_4branch.py精简示例
# branches 为四个参数独立的 DBSN
scales = (1.0, 0.5, 0.25, 0.125)
outputs = []
for scale, branch in zip(scales, branches):
    x_s = x if scale == 1 else F.interpolate(
        x, scale_factor=scale, mode="bilinear",
        align_corners=False)
    f_s = branch(x_s)
    f_s = F.interpolate(f_s, size=x.shape[-2:],
        mode="bilinear", align_corners=False)
    outputs.append(f_s)
restored = torch.stack(outputs).sum(dim=0)

为什么使用独立分支？

各尺度在自己的分辨率上学习：高分辨率保留局部纹理，低分辨率扩大上下文覆盖。分支参数互不共享。

为什么先对齐？

各分支输出的空间尺寸不同，上采样到输入尺寸后才能逐像素融合；当前代码采用逐元素相加。

实现依据

片段将已有四分支 forward 合并为循环，保留双线性缩放、独立处理、上采样与求和的逻辑。它是代码讲解，并非完整训练脚本。

两阶段的意义

先恢复、再估计结构，降低含噪观测对区域划分的干扰；固定权重避免训练过程中权重图随预测一起波动。

Explicit Multi-Scale Blind-Spot Denoising with Edge-Aware Spatial Loss ↗

Ming Cheng 等 · 第一作者 · 图像去噪 / 零样本学习

ABSTRACT / 论文摘要

盲点去噪在自监督图像去噪中取得了显著进展，但真实噪声在空间和尺度两个维度上存在明显的非均匀性。单尺度特征建模与空间均匀的损失函数容易造成纹理过度平滑、平坦区域去噪不足，难以兼顾细节保留和噪声抑制。为此，本文提出显式多尺度盲点去噪框架 EMBSD：在原始、1/2、1/4 与 1/8 分辨率上部署独立的膨胀盲点网络，同时捕获局部细粒度纹理和大尺度噪声波动；在优化层面，根据梯度幅值为不同区域分配重建损失权重，实现空间差异化去噪。真实图像去噪数据集上的实验表明，该方法在不同数据集上取得具有竞争力或更优的表现，并改善结构细节保留与噪声抑制。

英文摘要 · 原文

Blind-spot denoising (BSD) methods have made significant progress in self-supervised image denoising; however, noise in real-world images exhibits substantial heterogeneity across both spatial and scale dimensions. Existing single-scale feature modeling and spatially uniform loss functions often lead to over-smoothing in textured areas and insufficient denoising in smooth regions, struggling to balance detail preservation with noise suppression. To address these challenges, this paper proposes an Explicit Multi-Scale Blind-Spot Denoising (EMBSD) framework. Architecturally, we construct a four-scale multi-resolution network by deploying independent Dilated Blind-Spot Networks at the original resolution, as well as at 1/2, 1/4, and 1/8 scales, simultaneously capturing local fine-grained textures and large-scale noise fluctuations. For optimization, we introduce an edge-aware spatial loss weighting strategy that assigns different reconstruction loss weights to edge and flat regions based on gradient magnitude, thereby achieving spatially differentiated denoising. Experiments on real-world image denoising datasets demonstrate that EMBSD achieves competitive or superior performance across different datasets, with consistent improvements in structural detail preservation and noise suppression.

01

卷积与残差表征

局部连接 · 权重共享 · 感受野

卷积以局部邻域提取纹理，堆叠网络逐步扩大感受野。残差连接为信息与梯度提供更直接的传递路径，让深层网络更容易优化。

从局部算子到深层表征

卷积核在空间位置间共享参数，学习边缘、纹理等局部模式。连续堆叠扩大理论感受野；步长和膨胀率也会改变覆盖范围，但更大的感受野并不自动保证更好的细节恢复。

残差块学习 F(x)，输出为 x + F(x)。捷径提供直接的信息和梯度路径。图像去噪中的“预测噪声后相减”则是任务目标的设计，与残差块并非同一概念。

阅读重点：区分网络中的特征残差连接，与去噪任务中预测噪声残差这两种用法。

02

编码器—解码器与多尺度

下采样 · 跳跃连接 · 特征融合

低分辨率特征有助于捕捉较大范围的上下文，高分辨率特征保留位置与细节。编码器—解码器通过跨层连接结合两者。

分辨率与语义的协同

下采样减少计算并扩大上下文覆盖，但可能损失位置信息。解码器逐步恢复空间尺寸，跳跃连接将浅层细节传递到相应分辨率，融合前需确保尺寸对齐。

U-Net 的跨层连接与 EMBSD 的独立多尺度分支采用不同组织方式：前者连接编码与解码层级，后者在不同输入分辨率上分别建模后融合。

阅读重点：对比逐级下采样的单一路径、图像金字塔和并行多分辨率分支；关注融合位置与对齐方式。

03

注意力与视觉 Transformer

Q / K / V · Token · 全局交互

注意力根据输入内容调整特征之间的关联。视觉任务需进一步考虑图像的空间结构，以及高分辨率输入带来的计算与显存开销。

注意力计算了什么？

输入经线性映射得到 Q、K、V。Q 与 K 的相似度经缩放和 softmax 形成权重，再对 V 加权聚合；因此同一位置能按内容选择相关信息。

若有 N 个 token，全局空间注意力的关联矩阵包含 N² 个元素。窗口注意力限制交互范围以控制开销，但跨窗口信息仍需额外机制传递。位置编码或相对位置偏置则补充空间关系。

阅读重点：全局空间注意力、窗口注意力与通道注意力的建模范围不同；比较复杂度时需说明 token 数与通道数。

04

优化、归一化与训练

反向传播 · 学习率 · 正则化

反向传播计算梯度，优化器更新参数；学习率调度、初始化、归一化与数据划分共同影响收敛和泛化。训练稳定并不等同于验证效果更好。

优化收敛与泛化是两件事

每一步先前向计算目标，再反向传播得到梯度，最后由优化器更新参数。学习率影响更新幅度；权重衰减等正则化改变优化偏好，而验证集用于选择配置和检查泛化。

训练误差下降而验证误差回升可能提示过拟合。应先检查划分、数据泄漏与训练/推理模式，再考虑正则化、早停或调整学习率，不能仅凭训练损失挑选模型。

实践要点：监控训练与验证曲线；检查数据泄漏、梯度异常与随机种子；归一化层的训练和推理行为需要一致处理。

05

监督信号与自监督学习

干净标签 · 噪声对 · 盲点约束

监督学习使用输入与目标的配对关系。去噪中的自监督方法则利用噪声统计或空间约束构造学习信号；“无需干净标签”不代表不需要数据或假设。

监督来源决定适用条件

成对监督以干净图为目标；Noise2Noise 利用满足统计条件的噪声观测对；盲点方法限制模型读取中心像素，通过邻域预测构造自监督信号。

空间相关噪声可能让邻域携带目标噪声信息，破坏盲点方法依赖的条件。因此需要同时讨论噪声相关性、盲点构造、训练样本来源和测试时适应，不能只用“无干净标签”概括全部方法。

阅读重点：Noise2Noise 依赖相应的噪声统计条件；盲点方法依赖邻域可预测性与噪声条件。单图测试时适应和数据集训练也应分别讨论。

生成模型与图像先验

对抗学习 · 扩散过程 · 感知质量

生成模型学习图像分布，可为病态恢复问题提供先验。使用生成先验时，需同时关注视觉自然度、输入一致性与推理成本。

先验、保真与不确定性

GAN 通过生成器与判别器的对抗学习分布；扩散模型通过前向加噪与学习逆向过程建模图像分布。在修复任务中，这些生成先验还需要与退化模型或输入条件结合。

观测不足时，多种细节都可能与输入相容。更自然的纹理并不等于原场景真实细节；评估时应结合输入一致性、失真指标、主观质量和推理成本。

阅读重点：更自然的纹理可能并非原场景的真实细节；图像增强中应区分感知改善与可验证的信息恢复。

从模型到实验：还需要关注什么？

损失函数

L1 / L2 约束像素误差；感知损失比较特征差异；对抗目标强调分布与纹理。选择损失需要明确恢复精度与感知效果的侧重。

实验设计

先确定数据划分、退化设置和基线，再通过消融实验区分结构、损失与训练策略的贡献。避免同时改变多个变量。

复现与效率

记录配置、随机种子和模型权重；报告参数量、运行时间与测试分辨率。只有在相同硬件和推理设置下，效率比较才有意义。

  • Noise2Noise: Learning Image Restoration without Clean Data ↗

    在适当统计条件下从含噪目标学习，拓展了对训练标签的理解。

  • Noise2Void — Learning Denoising from Single Noisy Images ↗

02去模糊Deblurring恢复运动或散焦造成的边缘扩散和高频信息损失。＋
问题与建模y = k ∗ x + n

卷积模型适合描述部分模糊；真实运动模糊可能随空间位置变化。

方法脉络

对抗感知恢复 → 多阶段重建 → 高效注意力

核心难点

不同位置可能具有不同的运动轨迹；遮挡、饱和及极强模糊会使恢复更加不确定。需要警惕锐化光晕与重复边缘。

经典与代表论文

  • DeblurGAN: Blind Motion Deblurring Using Conditional Adversarial Networks ↗

    将条件对抗学习和内容损失结合，用于运动去模糊。

  • MPRNet · Multi-Stage Progressive Image Restoration ↗

    通过多个阶段和阶段间特征传递逐步恢复图像。

  • Restormer: Efficient Transformer for High-Resolution Image Restoration ↗

    围绕高分辨率修复优化注意力结构，覆盖运动与散焦去模糊等任务。

评测要点

区分运动模糊和散焦任务；比较 PSNR / SSIM、边缘清晰度与运行时间，确保相同测试设置。

03去阴影Shadow Removal消除光照遮挡影响，同时保持材质、颜色和非阴影区域一致。＋
问题与建模阴影定位 + 光照恢复

阴影不仅是整体变暗，还涉及软边界、光照颜色与区域之间的关系。

方法脉络

检测与去除联合建模 → 阴影图像分解

核心难点

阴影边界附近容易出现接缝；恢复亮度时也要避免改变物体固有颜色和非阴影区域。

经典与代表论文

  • ST-CGAN · Stacked Conditional Generative Adversarial Networks for Jointly Learning Shadow Detection and Shadow Removal ↗

    以串联条件 GAN 联合学习阴影检测与去除，让预测掩码辅助恢复。

  • Shadow Removal via Shadow Image Decomposition ↗

    通过阴影参数和 matte 层刻画阴影形成，将物理分解融入学习框架。

评测要点

分别检查阴影区、非阴影区与全图误差；比较 RMSE 时明确色彩空间和像素范围，并结合边界视觉检查。

04超分辨率Super-Resolution从低分辨率图像重建更高分辨率的结构和细节。＋
问题与建模y = ↓s (k ∗ x) + n

缩放因子、模糊核、噪声和压缩方式共同决定退化；双三次下采样仅是常用设置之一。

方法脉络

端到端卷积 → 深层残差 → 感知重建

核心难点

多个高分辨率图像可能对应同一低分辨率输入。真实退化与训练假设不匹配时容易出现伪纹理。

经典与代表论文

  • SRCNN · Image Super-Resolution Using Deep Convolutional Networks ↗

    通过卷积网络学习低分辨率到高分辨率的端到端映射。

  • EDSR · Enhanced Deep Residual Networks for Single Image Super-Resolution ↗

    调整残差模块并扩大模型规模，构建高性能重建网络。

  • ESRGAN: Enhanced Super-Resolution Generative Adversarial Networks ↗

    改进网络与感知训练以提升纹理自然度，适合讨论感知质量与像素误差的取舍。

评测要点

明确 ×2 / ×4 等放大倍数、退化方式、RGB 或 Y 通道和裁边设置；同时看失真指标与视觉真实性。

05低光增强Low-Light Enhancement提升暗部可见性，同时控制噪声、色偏与过曝。＋
问题与建模I = R ⊙ L

Retinex 将图像表示为反射与光照的乘积；实际成像还需考虑噪声与相机响应。

方法脉络

反射 / 光照分解 → 无参考曲线学习

核心难点

直接提高亮度会放大噪声；局部曝光、颜色自然度及高光保护需要共同考虑。

经典与代表论文

  • Retinex-Net · Deep Retinex Decomposition for Low-Light Enhancement ↗

    分解反射与光照，在光照分量上调整亮度，并考虑反射中的噪声。

  • Zero-DCE · Zero-Reference Deep Curve Estimation for Low-Light Image Enhancement ↗

    用无参考损失学习图像特定的增强曲线，无需正常曝光参考图像作为训练目标。

评测要点

有配对参考时使用 PSNR / SSIM；无参考时结合曝光、颜色、噪声与主观观察，避免用单一分数判断全部效果。

阅读图像修复论文的四个问题

退化是什么？

合成还是真实数据？已知还是未知退化？模型假设适用于哪些图像？

监督从哪里来？

是否有干净标签、成对图像或噪声统计假设？是否使用外部训练数据？

改进来自哪里？

网络结构、损失、数据或训练技巧各自贡献多少？消融设置是否公平？

结果怎样衡量？

指标、视觉效果、输入一致性与效率是否一起报告？比较协议是否统一？
